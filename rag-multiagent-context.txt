============================================================
EMBEDDINGS
============================================================
Port: Embedder.encode(texts) -> 2-D array-like
MiniLM: sentence-transformers all-MiniLM-L6-v2, cache .cache/sentence-transformers/ (gitignored)
Fallback: embedder=tfidf_fallback if import/download fails. Never crash the pipeline.
Unit tests: fake KeywordEmbedder; do not require MiniLM download.
Hybrid: RRF of neural cosine + SAST CWE ids + one-hop CWE relationships.

============================================================
DATA FLOW
============================================================
SeedUnit → Evidence[] → RankedHit[] → ReasoningResult → ValidationReport → Metrics

  dataset      load labels/split/source only
  sast         regex rules + binary detect() + Evidence spans (CWE hints, not encyclopedia)
  knowledge    CWE JSON store + query API
  retrieval    MiniLM or TF-IDF + SAST + relationship RRF; rank_for_unit; no reasoner
  schema       Draft 2020-12 validate helpers
  reasoner     TemplateReasoner / LLMReasoner (no dataset I/O)
  validator    schema + KB + cited lines + decision vs evidence
  orchestrator Pipeline.run; SAST-first; LLM only if key present
  framework    cwe-vuln-pipeline + cwe-vuln-eval
  cli          thin A1 / KB / retrieve / schema / evidence
  models       one Evidence, one ReasoningResult, one binary_metrics
  config       paths, top_k, rrf_k, LLM env names, use_llm_if_available, skip_llm_when_sast_hits

============================================================
LIMITATIONS
============================================================
- Seed-only 12-unit scores are distinct from research-split 24-unit scores.
- Research corpus is authored, small N, traps written against our regex.
- Validator requires decision to match SAST evidence, so LLM overrides fail A4 validation.
- MiniLM may be tfidf_fallback if the model is not cached / download failed.
- Live Groq waits on GROQ_API_KEY; default offline path is TemplateReasoner.
- CWE store is a curated subset, not a full MITRE dump.
- No Juliet / OWASP Benchmark / Big-Vul numbers.
