============================================================
ASSIGNMENT 2 — what landed (this PR)
============================================================
Curated JSON store: data/cwe/knowledge.json
  Six seed CWEs plus related parents/children/peers (real CWE ids only).
  Not an official MITRE dump.

Python API (src/cwe_vuln/knowledge.py):
  CWEKnowledgeBase.load()
  get(cwe_id) / search(text) / relationships(cwe_id) / mitigations(cwe_id) / neighbors(cwe_id)

CLI:
  uv run cwe-vuln-kb get CWE-89
  uv run cwe-vuln-kb search "sql injection"
  uv run cwe-vuln-kb relationships CWE-798
  uv run cwe-vuln-kb mitigations CWE-22
  uv run cwe-vuln-kb demo

search() is lexical token-overlap. Hybrid retrieval is Assignment 3 (not this PR).
