============================================================
DATA FLOW
============================================================
SeedUnit → Evidence[] → RankedHit[] → ReasoningResult → ValidationReport → Metrics

  dataset      load labels/split/source only
  sast         regex rules + binary detect() + Evidence spans (CWE hints, not encyclopedia)
  knowledge    CWE JSON store + query API
  retrieval    TF-IDF + SAST + relationship RRF; rank_for_unit; no reasoner
  schema       Draft 2020-12 validate helpers
  reasoner     TemplateReasoner.compose (no I/O, no LLM)
  validator    schema + KB + cited lines + decision vs evidence
  orchestrator Pipeline.run; SAST-first; skip LLM without key / when evidence exists
  framework    cwe-vuln-pipeline CLI + seed metrics
  cli          thin A1 / KB / retrieve / schema / evidence
  models       one Evidence, one ReasoningResult, one binary_metrics
  config       paths, top_k, rrf_k, LLM env names

LIMITATIONS
============================================================
- Seed-only evaluation (12 authored Java units / 18 retrieval queries).
- Retrieval is lexical TF-IDF, not neural embeddings. sentence-transformers was not added
  (keeps uv sync small/offline; A3 already documented this choice).
- Reasoner is a template composer; LLM path is skipped (no API key / not implemented).
- CWE store is a curated subset, not a full MITRE dump.
