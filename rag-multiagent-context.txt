============================================================
ARCHITECTURE (packages and data flow)
============================================================
See docs/architecture.md. Intended flow:

  SeedUnit → Evidence[] → RankedHit[] → ReasoningResult → ValidationReport → Metrics

Implemented modules now:
  dataset     load labels/split/source only
  config      top_k, rrf_k, LLM env names
  detector    regex rules + binary detect()
  knowledge   CWE JSON store + query API
  retrieval   TF-IDF + SAST signal + relationship RRF (no reasoner calls)
  schema      Draft 2020-12 JSON Schema + ReasoningResult to_dict/from_dict
  evaluate    A1 baseline metrics CLI

Not implemented yet: evidence product objects, reasoner, validator, orchestrator, framework CLI.
