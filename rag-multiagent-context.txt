first C2 sample with multi-file variants is archived under results/thesis/archive/).
Java units are teaching samples, not exploits.

Defendable contribution: a RAG-augmented detector of staged specialist agents
for six Java CWEs in which (1) SAST-style rules emit evidence, (2) hybrid MiniLM +
relationship/RRF retrieves CWE knowledge from an evidence/sink window, (3) a Groq
LLM produces A4-schema explanations, (4) a validator checks schema/lines/KB not
SAST agreement, (5) on an authored 24-unit FP/FN trap split, regex/template fail
and live LLM recovers most cases. Six-suite scores are method-vs-corpora evidence,
not a novelty proof. Public headline is C2 pair accuracy, not C1 F1.

============================================================
EMBEDDINGS
============================================================
Port: Embedder.encode(texts) -> 2-D array-like
MiniLM: sentence-transformers all-MiniLM-L6-v2, cache .cache/sentence-transformers/ (gitignored)
Fallback: embedder=tfidf_fallback if import/download fails. Never crash the pipeline.
Unit tests: fake KeywordEmbedder; do not require MiniLM download.
Hybrid: RRF of neural cosine + SAST CWE ids + one-hop CWE relationships.

============================================================
LLM (no OpenAI account)
============================================================
Primary key: GROQ_API_KEY   REQUIRED for default cwe-vuln-pipeline and
                             cwe-vuln-eval --suite research
Override: CWE_VULN_LLM_API_KEY
Do not tell Richa to create an OpenAI account.
Missing key → exit non-zero with a message to set GROQ_API_KEY.
Do not silently construct TemplateReasoner on the default path.

Default model: openai/gpt-oss-20b
Optional model: CWE_VULN_LLM_MODEL=openai/gpt-oss-120b
Default base URL: https://api.groq.com/openai/v1
Override: CWE_VULN_LLM_BASE_URL
Retired: llama-3.1-8b-instant (Groq free-tier 404). Do not use it.

Client: openai.OpenAI(api_key=..., base_url=...) OpenAI-compatible.
Load repo-root .env via python-dotenv. Never commit .env. Never print gsk_.

Default path → sast_then_llm / hybrid_retrieve_then_llm
--offline / --ablation template → TemplateReasoner (paper contrast; F1=0)
--ablation skip-llm → SAST hits use template; misses use LLM (opt-in)
Invalid JSON: retry once, then reasoner=llm_fallback_template
Tests mock the client. No live LLM calls in pytest.

  models       one Evidence, one ReasoningResult, one binary_metrics
  config       paths, top_k, rrf_k, LLM env names, use_llm_if_available, skip_llm_when_sast_hits

LIMITATIONS
============================================================
- Seed-only 12-unit scores, authored 36-unit scores, Juliet subset, and other public suites are separate tables.
- Research corpus is authored, small N, traps written against our regex.
- MiniLM may be tfidf_fallback if the model is not cached / download failed.
- Default live path requires GROQ_API_KEY; missing key fails clearly.
- CWE store is a curated subset, not a full MITRE dump.
- Juliet Java v1.3: NIST zip 403; GitHub mirror used. Missing CWE-79/22/502/798 folders.
- Juliet SAST n=20728 mapped/nearby folders only; LLM n=72 stratified sample (seed 13, 12/CWE × 6 ids).
- Six-suite LLM samples are n=12 per non-Juliet suite (seed 13), not full ingested sets. Regex ≠ CodeQL.
- CVEfixes-Java-slice is a GitHub Advisory maven slice (24 advisories), not the full CVEfixes dump.
- Not a claim of 100% novelty or SOTA.
